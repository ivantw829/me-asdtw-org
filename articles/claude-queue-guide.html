1. Claude Queue 能幫你做什麼

你在 claude.ai 打了一大段訊息，按下送出，才發現 5 小時用量或每週用量已經滿了。這時候只能把文字複製到別的地方，等額度恢復後再回來貼上。

裝了 Claude Queue 之後：

  1. 用量滿時按下送出，訊息會自動存進佇列（只存在你自己的電腦）
  2. 額度重置時，你會收到桌面通知
  3. 點通知會自動開啟原本的對話、把文字填回輸入框，你按「送出」就好

用量沒滿的時候，它完全不會干涉，跟沒裝一樣。

另外還有兩個選用功能（預設都關閉）：

  • 重置後自動送出：連「送出」都不用按
  • 自動重設：睡覺時工作階段一歸零就自動開始下一個，起床可以連用兩個工作階段（見第 10 節）

2. 開始之前：你需要準備什麼

項目說明
瀏覽器Google Chrome（版本 116 以上）。Edge、Brave、Arc 等理論上也能用，但沒有測試過
claude.ai 帳號在 Chrome 裡登入 https://claude.ai
使用環境只支援 claude.ai 網頁版（含 Projects）。不支援 Claude 桌面 App、手機 App、Claude Code

怎麼看 Chrome 版本

在網址列輸入 chrome://settings/help 按 Enter。

3. 下載

Claude Queue 目前還沒上架 Chrome 線上應用程式商店，要從 GitHub 下載原始碼來安裝。兩種方式選一種：

方式 A：下載 ZIP（推薦給一般使用者）

  1. 打開專案頁面：https://github.com/ivantw829/claude-queue
  2. 按綠色的 「Code」 按鈕 → 「Download ZIP」
  3. 下載完成後，解壓縮這個 ZIP 檔（macOS 雙擊即可；Windows 按右鍵 →「解壓縮全部」）
  4. 你會得到一個叫 claude-queue-main 的資料夾

重要：把資料夾放在固定的位置

把這個資料夾放到一個固定的位置，例如「文件」資料夾裡。Chrome 會直接從這個資料夾讀取擴充功能，安裝後不能刪除或移動它，不然擴充功能會失效。不建議放在「下載」資料夾，因為很容易被清掉。

方式 B：用 git（會用指令的人）

git clone https://github.com/ivantw829/claude-queue.git

之後更新只要 git pull（見第 12 節）。

4. 安裝到 Chrome

  1. 在 Chrome 網址列輸入 chrome://extensions，按 Enter
  2. 打開右上角的 「開發人員模式」 開關
  3. 左上角會出現幾個新按鈕，按 「載入未封裝項目」
  4. 選擇剛剛的 claude-queue-main 資料夾，按「選取」。要選的是裡面直接有 manifest.json 檔案的那一層；如果出現「找不到資訊清單檔案」的錯誤，通常是選到外面一層，請點進去一層再選
  5. 擴充功能清單裡出現 Claude Queue 就代表安裝成功

把圖示釘選到工具列

  1. 按 Chrome 右上角的 拼圖圖示 🧩
  2. 找到 Claude Queue，按旁邊的 圖釘 📌

這樣工具列上就會一直顯示 Claude Queue 的圖示，方便查看用量和佇列。

重新整理 claude.ai 分頁

已經開著的 claude.ai 分頁要重新整理一次（按 ⌘ R 或 Ctrl R），擴充功能才會在那個分頁生效。之後新開的分頁不用。

5. 確認安裝成功

  1. 打開（或重新整理）https://claude.ai，確認已登入
  2. 等幾秒，按工具列上的 Claude Queue 圖示
  3. 小視窗上方應該會顯示 Session（5 小時） 和 每週 兩條用量條，有百分比數字；下面一行是「來源：… · N 分鐘前更新」

看到用量百分比，就代表一切正常。

如果顯示「尚無用量資料，開啟 claude.ai 後會自動偵測」，請確認你有開著 claude.ai 分頁並且已經重新整理過，然後按小視窗右上角的 ⟳ 重新查詢。

6. 開啟桌面通知

額度重置的提醒是用系統的桌面通知，所以要確認作業系統允許 Chrome 發通知：

  • macOS：「系統設定」→「通知」→ 找到 Google Chrome → 打開「允許通知」。建議把提示樣式設成「提示」（會停留在畫面上，不會自動消失）
  • Windows：「設定」→「系統」→「通知」→ 確認 Google Chrome 是開啟的

Claude Queue 本身的通知預設就是開啟的（可在設定頁關閉）。

7. 日常使用

平常：什麼都不用做

用量沒滿時，你照常使用 claude.ai 就好，Claude Queue 不會攔截任何東西。

用量滿了：照常按送出

  1. 照常輸入訊息，按 Enter 或送出按鈕
  2. Claude Queue 會攔下這次送出、確認真的滿了，把訊息存進佇列
  3. 確定存好之後才會清空輸入框，頁面下方會出現提示：「用量已滿，訊息已排入佇列，預計 HH:MM 重置」。
  4. 工具列圖示會出現數字，代表佇列裡有幾則訊息。

數字的顏色代表狀態：

  • 橘色：等待重置中
  • 綠色：已經可以送出
  • 紅色：有送出失敗的訊息

關於「時間為估計」

重置時間後面如果有「（時間為估計）」，代表 Claude Queue 沒辦法讀到精確的時間，是推估出來的。

有附件或圖片的訊息不會被排隊

這時頁面會提示「此訊息含附件，無法自動排隊」，照 claude.ai 原本的方式處理。

額度重置後：點通知 → 按送出

  1. 到了重置時間，你會收到桌面通知 「Claude 額度已重置」
  2. 點通知 → 自動開啟原本的對話，文字已經填回輸入框
  3. 頁面下方出現確認列 「已還原訊息，要送出嗎？」，有三個按鈕：
按鈕會發生什麼事
送出幫你按下送出，確認訊息真的出現在對話裡之後，才從佇列移除
取消從佇列移除這則訊息，文字留在輸入框讓你自己處理
保留在佇列清空輸入框，訊息繼續留在佇列，之後可以從小視窗再試

同一個對話如果排了好幾則訊息，會等 Claude 回應完成後，再依序還原下一則。

錯過通知也沒關係

按工具列圖示，在佇列裡找到那則訊息，按 「立即嘗試」 就好。

8. 工具列小視窗（popup）

按工具列上的 Claude Queue 圖示，會打開一個小視窗：

  • 用量：5 小時和每週用量的百分比、什麼時候重置、還剩多久
  • ⟳（右上角）：立即重新查詢用量（需要開著 claude.ai 分頁）
  • ⚙（右上角）：打開設定頁
  • 佇列：每則排隊中的訊息，可以編輯文字、立即嘗試（馬上開啟原對話並還原），或刪除（要按兩次才會刪除，避免誤刪）

訊息前面的標籤代表狀態：等待重置、可送出、送出中、失敗、草稿、自動重設。

9. 設定頁

打開方式：小視窗右上角的 ⚙，或在 chrome://extensions 找到 Claude Queue →「詳細資料」→「擴充功能選項」。

送出

設定預設說明
重置後自動送出（不需確認）關閉額度重置後自動開啟原對話、填入文字，倒數 3 秒後送出（倒數時可以取消）。注意：你不在電腦前時也會送出，對話情境可能已經改變，送出後無法撤回
桌面通知開啟額度重置時發通知。關閉後只會在工具列圖示顯示數量
用量輪詢頻率2 分鐘開著 claude.ai 時多久查詢一次用量（1–30 分鐘），一般不用改

自動重設

設定預設說明
工作階段歸零時自動送出一則訊息關閉見下一節
要送出的訊息Hello World!越短越省額度，最多 200 字

除錯與資料

  • 記錄 debug log：遇到問題要回報時再開。log 只記錄事件和狀態，不記錄訊息內容
  • 模擬「用量已滿」：不用真的把額度用完就能試用（見第 11 節）
  • 清除所有資料：刪除佇列、用量快取、log 和設定。注意：佇列中還沒送出的訊息會被永久刪除

10. 進階：睡覺時自動重設，起床連用兩個工作階段

為什麼有用？

claude.ai 的 5 小時工作階段，要等你送出第一則訊息才開始倒數。如果工作階段在你睡覺時結束，它就會一直停在歸零，直到你起床送出第一則訊息才重新開始。

開啟「自動重設」後，工作階段一結束，Claude Queue 就會自動送出一則短訊息，讓下一個工作階段馬上開始倒數。

舉例：

沒開自動重設開了自動重設
凌晨 3:00工作階段結束，停在歸零工作階段結束，自動送出訊息，新的工作階段開始（8:00 結束）
早上 7:00 起床送出第一則訊息，工作階段開始（12:00 結束）目前的工作階段還能用 1 小時
早上 8:00還在同一個工作階段重置！再接一個完整的新工作階段

怎麼開啟

  1. 打開設定頁 →「自動重設」
  2. 勾選 「工作階段歸零時自動送出一則訊息」，在確認框按「確定」
  3. （選用）修改「要送出的訊息」，預設是 Hello World!
  4. 打開工具列小視窗，下方會顯示「自動重設：開啟 · 約 HH:MM 送出」

第一次送出時會自動開一個新對話，之後都送進同一個對話，不會讓你的對話清單變亂。如果你刪掉那個對話，下次會自動再開一個。

睡前檢查清單

自動重設要在電腦醒著、Chrome 開著的時候才能運作，睡前請確認：

  • Chrome 保持開啟（可以最小化，但不要整個關掉）
  • claude.ai 保持登入
  • 筆電建議接上電源
  • 電腦不能睡眠（做法見下）

macOS：打開「終端機」，貼上下面的指令並按 Enter，終端機視窗開著的期間電腦就不會進入睡眠（螢幕還是可以關）。早上按 Ctrl C 結束。

caffeinate -i

也可以到「系統設定」→「電池」（桌機是「能源」）調整，避免電腦自動睡眠。

Windows：「設定」→「系統」→「電源」→ 把「睡眠」設為「永不」。

要知道的事

  • 送出時會把 Chrome 視窗帶到最前面（需要讓輸入框取得焦點才能填入文字）。這個功能全天運作，白天工作階段結束時也會
  • 每次會用掉一點點額度（就是一則短訊息和 Claude 的回覆）
  • 每週上限已滿時不會送
  • 如果佇列裡剛好有訊息正在自動送出，就不另外送（那則訊息本身就會開始新的工作階段）；你已經用手機送過訊息時也不會送
  • 連續失敗 3 次會暫停並發通知。你再次使用 Claude，或關掉再打開這個設定，就會恢復

11. 不用等額度用完，先試玩一次

想先看看整個流程長什麼樣子，可以用「模擬」：

  1. 打開設定頁 →「除錯」→ 勾選 「模擬『用量已滿』」，旁邊填 2（2 分鐘後重置）
  2. 到 claude.ai 隨便打一句話，按送出 → 訊息被存進佇列，輸入框被清空
  3. 打開工具列小視窗，看到佇列裡有一則「等待重置」的訊息
  4. 等大約 2–3 分鐘 → 收到「Claude 額度已重置」通知
  5. 點通知 → 文字填回輸入框 → 按「送出」或「取消」試試看
  6. 試完記得回設定頁把模擬關掉

同時開著自動重設的話

如果你同時開著「自動重設」，模擬結束時它會真的送出一則訊息。只想試排隊功能的話，先把自動重設關掉。

12. 更新到新版本

用 ZIP 安裝的

  1. 到 https://github.com/ivantw829/claude-queue 重新下載 ZIP 並解壓縮
  2. 用新資料夾的內容覆蓋原本安裝的資料夾（位置要一樣）
  3. 到 chrome://extensions，按 Claude Queue 卡片上的 重新載入 按鈕 ↻
  4. 重新整理 claude.ai 分頁

用 git 安裝的

git pull

然後一樣到 chrome://extensions 按 ↻，再重新整理 claude.ai 分頁。

怎麼確認更新成功

小視窗標題旁邊會顯示目前的版本號（例如 v0.2.0），可以用來確認更新成功。佇列和設定在更新時都會保留。

13. 移除

  1. 到 chrome://extensions
  2. 在 Claude Queue 卡片上按 「移除」
  3. 之後就可以刪掉 claude-queue-main 資料夾

注意：移除時，佇列裡還沒送出的訊息會一起被刪除。要保留的話，先在小視窗用「編輯」把文字複製出來。

14. 疑難排解

用量滿了卻沒有攔截

  • 這個分頁是在安裝之前就開著的嗎？重新整理一次
  • 打開小視窗，看用量是否正常顯示。如果顯示「用量端點讀取失敗」，可能是 claude.ai 改版了，請回報（見下方）

頁面跳出「找不到頁面元素…介面可能已改版」

  • claude.ai 改了頁面結構，需要更新擴充功能。先看看 GitHub 有沒有新版本，沒有的話請回報

沒有收到通知

  • 確認第 6 節的系統通知設定
  • 確認設定頁的「桌面通知」是開啟的
  • 檢查 macOS 是否開了「專注模式／勿擾模式」
  • 沒收到也沒關係，打開小視窗，綠色的訊息可以直接按「立即嘗試」

通知寫「預計已重置（尚未確認）」

  • 重置時你沒開著 claude.ai，所以沒辦法先確認。點通知開啟對話後會再查一次，如果還沒重置，訊息會放回等待，不會硬送

重新開啟 Chrome 之後擴充功能不見了／出現錯誤

  • 你可能移動或刪除了安裝用的資料夾。把資料夾放回原位，或重新做一次第 4 節

自動重設沒有送出

  • 確認睡前檢查清單：電腦有沒有睡著、Chrome 有沒有被關掉、claude.ai 是不是被登出了
  • 打開小視窗，看「自動重設」那一行有沒有顯示「上次失敗：…」

回報問題

  1. 設定頁 → 勾選 「記錄 debug log」
  2. 重現一次問題
  3. 設定頁 → 「複製 log」（log 不含訊息內容）
  4. 貼到下面任一個地方，並說明你的 Chrome 版本和操作步驟。
