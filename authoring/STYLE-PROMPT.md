# 設計風格提示詞：「溫暖人文 × 角色識別」

> 用法：把下面「▼ 提示詞」整段貼給 AI，再附上你這次的內容（頁面目的、文案、需要的元件、可選的角色插畫）。
> 想換成別的身分或品牌，只要替換第 13 節的「可替換的識別」，其餘結構都能沿用。

## ▼ 提示詞（從這裡開始複製）▼

你是一位資深網頁設計師與前端工程師。請依照下面的「設計風格」設計我指定的頁面，風格要與我提供的參考一致，不要自行改成別的風格。

### 1. 風格一句話
**溫暖人文的紙張感 × 街頭海報式的角色識別。** 像一本手作的獨立雜誌：米白紙張底、琥珀黃螢光筆、青綠色圓形與墨黑名字標籤；襯線標題帶文藝感，黑體內文保持易讀；少量條碼、鏤空大字、×／＋ 符號帶來「身分證／海報」的俏皮感。整體親切、有人味、有行動的力道，**不要冷冰冰、不要企業風、不要科技藍紫漸層。**

### 2. 設計原則
1. **紙張感，不是純白。** 底色是帶一點黃的奶白，卡片比底色再亮一點，彷彿紙疊紙。
2. **用螢光筆強調，不用粗暴強調。** 重點文字底下刷一道淡黃色，而不是整段加粗變色。
3. **黃色是唯一的主動色。** 按鈕、目前所在、重點標籤用黃；青綠只做大色塊與鏤空字；墨黑只做名字標籤與小圖示。
4. **裝飾集中在首頁主視覺，內文頁要克制。** 文章、說明、表單頁不放條碼、鏤空字、×。
5. **柔和圓角、淡暖色陰影。** 圓角 14px，陰影帶棕色而不是灰黑。
6. **一頁一個焦點。** 版面留白寬鬆，行距大，不堆資訊。

### 4. 字體與字階
- 字體（Google Fonts）：`Noto Serif TC`（500、700、900）用於標題；`Noto Sans TC`（400、500、700、900）用於內文與介面。
- **襯線字用在：** 所有標題（h1～h3）、一句話摘要、引言、金句、提示框標題、名字標籤、時間軸年份。**黑體用在：** 內文、清單、按鈕、標籤、圖說、導覽。
- 內文 `17px / 行高 1.8 / letter-spacing .01em`（手機 16px）；長文 `1.06rem / 行高 1.95`，欄寬 `40rem`。
- 字階：首頁主標 `clamp(2.2rem, 7vw, 3.4rem)`；頁面標題 `clamp(1.9rem, 5vw, 2.6rem)`；區塊標題 `1.6rem`；卡片標題 `1.2rem`。
- **Eyebrow（小標前綴）**：英文大寫、`.85rem`、`letter-spacing .12em`、`--accent-ink`、字重 500，放在頁面標題上方（例如 `ABOUT`、`EXPERIENCE`）。
- 繁體中文排版：全形標點，中文與英數之間加半形空格，引號用「」。

### 5. 版面
- 內容寬度 `min(100% - 32px, 1080px)` 置中（左右各留 16px）；長文欄寬 `40rem`。
- 區塊上下間距 `56px`（手機 `40px`）；卡片格線 `repeat(auto-fill, minmax(min(100%, 300px), 1fr))`，間距 `20px`。
- **頁首**：黏在頂端、背景為 `--bg` 88% 透明加 `blur(10px)`、底部 1px `--line`。左邊是品牌（34px 圓形頭像 + 2px 黃色外圈 + 襯線名字），右邊是導覽與深色模式按鈕。**目前所在頁的導覽項目是黃色藥丸**，其餘為灰字，hover 時淡底。手機寬度（≤560px）導覽換到第二行、撐滿寬度。
- **頁尾**：上方 1px 分隔線；社群連結一行；虛線分隔後「友站」一行；最後是小字聲明。

### 6. 基礎元件規格
- **按鈕**：全圓角膠囊（`999px`）、`1.5px` 墨色外框、`padding 10px 20px`、字重 500。主要按鈕改為黃底深字、無外框差異。hover：次要按鈕變 `--surface-2`、主要按鈕微亮。
- **標籤／chip**：膠囊、`--accent-soft` 底、`--accent-ink` 字、`.85rem`；可篩選的標籤被選取時改為黃底深字。
- **卡片**：`--surface` 底、`1px --line` 邊框、圓角 14px、`padding 22px`、淡暖陰影；hover 上浮 `2px` 並把邊框變黃；**整張卡片可點擊**（標題連結的 `::after` 撐滿卡片）。
- **連結列表**：每列一個圓角框，左邊標籤、右邊灰色小字說明；hover 邊框變黃。
- **內文 h2**：左側 5px 黃色粗線，`padding-left 14px`。
- **粗體 `<strong>`**：不加深色，而是下方 35% 刷一道 `--accent-soft`（螢光筆）。
- **引言 blockquote**：左側 4px 黃線、襯線字 `1.12rem`；出處用黑體灰小字。
- **金句 pullquote**：襯線 `1.5rem` 置中，上下各一條 `48×3px` 黃色短線。
- **提示框 callout**：`--accent-soft` 底、`1px` 40% 黃色邊框、圓角 12px，標題用襯線粗體。
- **名字標籤**：`--ink` 底、`--paper` 字、襯線、`letter-spacing .35em`，像貼在身分證上的黑色標籤。
- **一句話標語 tagline**：襯線、灰字，前面一條 `36×6px` 的墨色圓角短線。

### 7. 首頁主視覺公式（Hero）
兩欄（`1.15fr : 1fr`，手機改為上下堆疊）。
- **左欄**：eyebrow → 名字標籤（h1）→ 標語 → 1～2 句介紹（最寬 34rem）→ 兩個按鈕（主要＋次要）。
- **右欄（角色區，3:4 比例）**：由後到前疊：
  1. **青綠大圓**（寬度 92%，置中偏上）。
  2. **鏤空大字**（角色代號或姓名縮寫，字重 900、`-webkit-text-stroke: 2px var(--teal)`、字色透明、`clamp(3.6rem, 13vw, 5.4rem)`），放在角色後方的左下角。
  3. **角色去背圖**，加上 **硬陰影** `filter: drop-shadow(10px 8px 0 var(--accent))`，形成「黃色偏移描邊」的海報感。
  4. **三個「×」**（黃色、2rem）垂直排在右上角。
  5. **CSS 條碼**（`repeating-linear-gradient` 畫出粗細交錯的直線，約 `74×38px`、透明度 .75）放在左上角。
- 沒有角色插畫時：用「青綠圓 + 黃色偏移圓 + 鏤空縮寫字」組出同樣構圖。
- 主視覺下方接一條「議題／標籤」橫條：卡片底、左邊一個青綠的 `+` 號。

### 8. 進階元件（需要時使用）
- **科技樹（技能／經歷樹狀圖）**：頂端黃色膠囊根節點（外圈 `0 0 0 6px --accent-soft` 光暈）→ 一條 2px 垂直線 → 兩欄分支卡片。卡片內為縮排清單，**以 2px `--line` 畫連接線與橫向短刻度**；分類名稱用襯線粗體並以黃色 `◆` 開頭；葉節點是一般文字，後面接「角色藥丸」（淡黃底；重點成果用實心黃底）。
- **時間軸**：左側 2px `--line` 直線；每個節點是 12px 黃色圓點（外圈 4px 底色）；年份用襯線標題、底下 2px 黃線；節點內第一行是「日期 + 類別標籤」，第二行是標題（可含連結），第三行是灰色「角色」。
- **彈窗（Dialog）**：置中卡片，上方 72px 墨色圓形徽章（外圈 5px 黃色），背景遮罩為 `--bg` 混黑再模糊（`blur(14px)`）；主要按鈕黃底、次要按鈕外框。
- **表格**：只用橫向 1px 分隔線，表頭用 `--surface-2` 底 + 襯線字，窄螢幕可橫向捲動。

### 9. 動態
- 互動：卡片 hover `translateY(-2px)`、導覽與按鈕的底色／字色 `0.2s` 過渡，不要彈跳、旋轉或視差。
- **跨頁切換（多頁網站）**：使用 CSS View Transitions，`@view-transition { navigation: auto; }`。舊頁面 `0.16s` 淡出並上移 6px；新頁面 `0.34s` 從下方 12px 淡入（`cubic-bezier(.2,.8,.2,1)`）；導覽目前所在的黃色藥丸設 `view-transition-name`，讓它**滑動**到新的位置。頁首固定不動。
- 必須尊重 `prefers-reduced-motion`：偏好減少動態時關閉所有轉場與動畫。

### 10. 深色模式
- **不是單純反相**，而是「暖黑褐底 + 奶白字」：底色 `#1a1612`、卡片 `#231e18`；黃色略調亮為 `#f2b84b`；青綠調亮為 `#7fb0b4`；名字標籤反白成奶白底。
- 右上角圓形切換鈕（38px，月亮 ☾／太陽 ☀），偏好存在 `localStorage`，沒有偏好時跟隨 `prefers-color-scheme`。
- 在 `<head>` 內放一小段行內腳本，**先套用主題再繪製**，避免閃白。

### 11. 無障礙與響應式
- 對比：連結文字用 `--accent-ink`，黃色只當底色；`:focus-visible` 一律 3px `--accent` 外框；提供「跳到主要內容」連結。
- 手機優先：單欄、觸控目標至少 38px、圖片都有 `alt`、所有互動元件可用鍵盤操作。
- 列印時隱藏頁首、頁尾、留言與互動元件。

### 12. 不要做的事
- 不要純白（`#fff`）或純黑（`#000`）；不要紫藍漸層、霓虹、玻璃擬態。
- 不要重陰影、不要大面積灰色細字；不要把黃色用在長段文字。
- 不要用黑體當標題（標題一律襯線）；不要用 emoji 當裝飾（裝飾符號只用 ◆ × ＋ 與條碼）。
- 不要輪播、視差、自動播放；不要同一區塊混用超過兩種裝飾。
- 不要使用素材庫插圖；角色圖以使用者提供的為準。

### 13. 可替換的識別（換成別人或別的品牌時只改這些）
- **主色（黃）**、**副色（青綠）**、**墨色**：三色比例約為 黃 10%、青綠 5%、墨 2%，其餘為奶白與暖灰。
- **角色／標誌圖**與 **鏤空字內容**（代號、縮寫）。
- **名字標籤文字**與 **標語**。
- 保持不變：紙張感底色、襯線標題＋黑體內文、膠囊按鈕、14px 圓角、螢光筆強調、裝飾只在首頁的原則。

### 14. 輸出要求
1. 先用 3～5 句話說明你如何把這個風格套用到我的頁面，再給程式碼。
2. 使用語意化 HTML、**CSS 變數（直接使用第 3 節的名稱）**與原生 JavaScript，除非我另外要求，不要引入框架。
3. 同時提供淺色與深色模式，並確認 375px 手機寬度與 1280px 桌面寬度都沒有橫向捲軸。
4. 若為了內容需求必須偏離風格（例如需要新元件），請指出偏離了哪一點、為什麼。
5. 完成後用第 12 節逐項自我檢查，列出通過與未通過的項目。
