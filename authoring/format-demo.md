這篇是寫作格式的對照表。每一節先放 Markdown 的寫法，接著是它在網站上實際顯示的樣子，最後說明適合用在什麼情況。發文流程請看 `authoring/AI-PROMPT.md`。

[[目錄]]

## 標題與段落

### 寫法

```
## 大標
### 小標
一般段落直接寫，段落之間空一行。
```

### 顯示

上面這一節的「標題與段落」就是大標，「寫法」「顯示」是小標，你正在讀的這行就是段落。文章的第一段字級會稍大一點，用來交代緣起。

### 什麼時候用

- **大標**：切分文章的主要章節。超過約 800 字就該分節，一節約 200～400 字。
- 小標：大標底下還要再細分時才用，不要跳過大標直接用小標。
- 不要用 `#`（一個井號）：那是文章標題，由 frontmatter 的 `title` 產生。
- 整行只有粗體（例如單獨一行 `**某某**`）會被當成小標，想強調請放在句子裡。

## 粗體、連結與行內程式碼

### 寫法

```
這句有 **重點**，這裡有 [連結文字](https://example.com)，指令用 `python3 check.py`。
直接貼網址也會變成連結：https://me.asdtw.org
```

### 顯示

這句有 **重點**，這裡有 [連結文字](https://example.com)，指令用 `python3 check.py`。

直接貼網址也會變成連結：https://me.asdtw.org

### 什麼時候用

粗體會有螢光筆效果，一段最多一處，標太多就沒有重點。站外連結會自動在新分頁開啟。檔名、指令、按鈕名稱這類「要照打」的文字用行內程式碼。

## 清單

### 寫法

```
- 無序清單
- 順序不重要的重點

1. 有序清單
2. 有先後順序的步驟
```

### 顯示

- 無序清單
- 順序不重要的重點

1. 有序清單
2. 有先後順序的步驟

### 什麼時候用

三個以上並列的重點用無序清單；教學步驟、排名這類順序有意義的內容用有序清單。只有一兩點時，寫成段落通常比較順。

## 引言

### 寫法

```
> 引用別人說過或寫過的話，可以有好幾行。
> — 出處（人名、書名或媒體）
```

### 顯示

> 引用別人說過或寫過的話，可以有好幾行。
> — 出處（人名、書名或媒體）

### 什麼時候用

引言是「別人的話」：訪談、書籍、法條、新聞原文。最後一行以「—」開頭就會變成出處。自己的話想強調，請改用下面的金句。

## 提示框

### 寫法

```
[[提示框：提示框標題]]
提示框內文，寫到空行為止。
```

### 顯示

[[提示框：提示框標題]]
提示框內文，寫到空行為止。

### 什麼時候用

跟主線不同、但讀者可能需要的資訊：名詞解釋、背景說明、注意事項、版本差異。讀者跳過也不影響理解主文時，才適合放進提示框。

## 金句

### 寫法

```
[[金句：一句最想讓讀者記住的話。]]
```

### 顯示

[[金句：一句最想讓讀者記住的話。]]

### 什麼時候用

整篇文章的核心觀點，而且是自己的話。一篇最多 2 個，用多了會失去份量。

## 表格

### 寫法

```
| 格式 | 內容來源 | 用途 |
| --- | --- | --- |
| 引言 | 別人的話 | 引用 |
| 金句 | 自己的話 | 強調 |
| 提示框 | 補充資訊 | 說明 |
```

### 顯示

| 格式 | 內容來源 | 用途 |
| --- | --- | --- |
| 引言 | 別人的話 | 引用 |
| 金句 | 自己的話 | 強調 |
| 提示框 | 補充資訊 | 說明 |

### 什麼時候用

需要「多個項目 × 多個面向」對照時，例如比較方案、整理規格。只有一個面向的話，用清單就好。手機上表格太寬會左右捲動，欄位盡量少於 4 欄。

## 圖片

### 寫法

```
![圖說，同時是給看不到圖片的人的描述](demo.png)
```

### 顯示

![本站的社群分享卡片：左側是網站名稱，右側是角色插圖](demo.webp)

### 什麼時候用

截圖、照片、示意圖。圖說要描述圖片內容（它同時是 `alt` 替代文字），不要只寫「圖一」。png、jpg 會自動轉成 webp 並壓縮；檔名用 `cover.png` 的圖會變成文章頂端的封面，並裁成 16:9。

## 程式碼區塊

### 寫法

用三個反引號（`` ` ``）各自獨立一行，把程式碼包起來，就是本文每一節「寫法」底下的那種灰底區塊。

### 什麼時候用

多行的指令、設定檔、程式碼，或像本文這樣要原封不動顯示的文字。區塊裡的內容不會被轉換格式。

## 分隔線與目錄

### 寫法

```
---

[[目錄]]
```

### 顯示

---

本文開頭的「本文目錄」就是 `[[目錄]]` 產生的，會列出所有大標並可點擊跳轉。

### 什麼時候用

分隔線用在話題明顯轉換、但還不到要另開一個大標的地方，平常很少需要。目錄只在長文（大標 4 個以上）放，短文放了反而佔版面。

## 參考資料區塊

### 寫法

```
## 參考資料

1. 作者，〈標題〉，媒體名稱，2026-11-16，[連結](https://example.com)
```

### 顯示

請看本文最下方的「參考資料」區塊。

### 什麼時候用

文中引用的數據、新聞、論文都列在這裡，一律放在原稿最後。沒有引用就不要寫這一節。
